# Base de datos de FitTrack

Esta carpeta contiene los scripts SQL oficiales del proyecto.

## Convenciones

- Numerar los scripts según su orden de ejecución.
- No subir contraseñas ni credenciales.
- Probar los cambios en MySQL antes de compartirlos.
- Documentar las modificaciones de estructura.
- Mantener los scripts existentes para conservar el historial.

Los nombres y el orden definitivos de los scripts se acordarán
cuando se entregue el esquema de la base de datos.
